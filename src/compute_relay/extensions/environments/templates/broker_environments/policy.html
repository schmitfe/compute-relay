Environment build permission

This administrator policy is separate from an agent's API key. It must explicitly enable builds, select existing bootstrap environments and pin the expected compute Python/platform. Builds also need the ordinary project compute allowance and submission slots.

The available builder creates Python virtual environments from an empty standard-library environment or uploaded, pinned wheels. Conda, micromamba and Poetry builders are not available yet.
