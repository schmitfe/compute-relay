# Hybrid Ornstein-Uhlenbeck replication acceptance

- [ ] **target_gate**: Use only assigned targets and report missing capabilities/extensions.
- [ ] **budget**: Record live allowance before/after, resource bounds, and settled zero reservations.
- [ ] **evidence**: Hash every output and identify code/config, seeds, native execution IDs and limitations.
- [ ] **derive_pilot**: Derive finite-time OU second moment and validate a deterministic local pilot.
- [ ] **replicates**: Run four explicitly seeded cluster replicas; no duplicate seed or blind resubmission.
- [ ] **local_analysis**: Retrieve/hash small summaries and combine moments locally with an approximate uncertainty interval.
